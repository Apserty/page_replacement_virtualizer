Principles of Operating Systems — Educational Guide

Core concepts of Virtual Memory and Page Replacement Algorithms.

Virtual Memory & Paging

Virtual memory separates user logical memory from physical memory, enabling execution of processes that may not be completely in memory.

  • Page: Fixed-size block of logical memory.
  • Frame: Fixed-size block of physical memory (RAM).
  • Page Hit: Requested page already resides in a frame.
  • Page Fault: Requested page is not present in physical frames and must be fetched from backing store.

FIFO (First-In, First-Out)

The simplest page-replacement algorithm. When a page must be replaced, the oldest page (the one brought into memory first) is chosen as the victim.

  • Managed via a FIFO queue of frame arrivals.
  • Easy to implement and low overhead.
  • Subject to Belady's Anomaly (more frames may result in more page faults).

LRU (Least Recently Used)

Replaces the page that has not been referenced for the longest period of time. Approximates optimal replacement by looking into the recent past.

  • Based on the principle of temporal locality.
  • Immune to Belady's Anomaly (stack algorithm).
  • Requires hardware or timestamp tracking support.

Optimal Algorithm (OPT / Belady's)

Replaces the page that will not be used for the longest period of time in the future. Guarantees the lowest possible page fault rate.

  • Requires future knowledge of reference strings.
  • Used primarily as a theoretical benchmark for evaluation.
  • Immune to Belady's Anomaly.
